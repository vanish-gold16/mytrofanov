# Ivan Mytrofanov Portfolio

Minimal personal portfolio built with plain HTML and CSS.

## Structure

- `index.html` - main page.
- `wayoni/index.html` - Wayoni page, served at `/wayoni`.
- `components/site-header.js` - shared header element.
- `styles/main.css` - global styles.
- `public` - static assets.
- `public/logo.png` - logo file used in the header.
